# Componentes incluidos

- **Python 3.14.7 Portable para Windows x64.** Su licencia está en `runtime/python/LICENSE.txt`. [Distribución oficial](https://www.python.org/ftp/python/3.14.7/), [código fuente](https://github.com/python/cpython/tree/v3.14.7).
- **Node.js 24.22.1 para Windows x64.** Su licencia y los avisos que incluye el proveedor están en `Licencias/Node.js.txt`. [Distribución y código fuente](https://nodejs.org/dist/v24.22.1/).
- **FFmpeg 9.0.2 Essentials Build para Windows x64.** Surco ejecuta el binario de Gyan como proceso independiente. Su licencia GPLv3 y la configuración de compilación se incluyen en `Licencias/`. [Binario original](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2), [fuentes de FFmpeg de esa compilación](https://github.com/FFmpeg/FFmpeg/archive/946fcce07b.tar.gz), [bibliotecas de la compilación](https://www.gyan.dev/ffmpeg/builds/#libraries).
- **Paquetes de Python y Rust.** Las licencias y avisos se incluyen en `runtime/python/Lib/site-packages` y en `Licencias/Rust`. Las versiones exactas se fijan en `requirements.txt` y `Cargo.lock`.
- **Glasswork 1.1.0.** La interfaz incluye su efecto visual bajo la licencia MIT. [Código y licencia](https://github.com/kubai087/glasswork/tree/v1.1.0).
